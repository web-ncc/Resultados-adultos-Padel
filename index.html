Grupos Liga

Criterio de clasificación:

Empate entre 2 parejas:
1. Número de victorias.
2. Enfrentamiento directo.

Empate entre 3 parejas:
1. Victorias obtenidas entre las parejas empatadas.
2. Diferencia global de juegos.
3. Si persiste el empate, diferencia de juegos únicamente entre las parejas empatadas.
4. Si después quedan solamente 2 parejas empatadas, enfrentamiento directo entre esas dos.

Cuartos de final

Clasificados: 2 primeros de los Grupos 1 y 2, 3 primeros del Grupo 3, y el mejor 3.º entre los Grupos 1 y 2.

El mejor 3.º se determina por:
1. Número de victorias.
2. Diferencia global de juegos.
3. Juegos a favor.

El ranking posterior ordenará a los clasificados según el criterio establecido.
